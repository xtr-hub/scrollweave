# Release status — ScrollWeave Python/Rust 0.9.1

**Rust-core Python library; native build and regression tests verified on Windows (Rust 1.93.1, Python 3.12.7). Published to PyPI as [`scrollweave 0.9.1`](https://pypi.org/project/scrollweave/0.9.1/); a fresh-venv `pip install scrollweave==0.9.1` and installed smoke test passed.**

Runtime dependency declarations: zero Python packages and zero third-party Cargo crates. Compilation requires installed Rust/Cargo and a platform linker. Native reconstruction algorithms are implemented in Rust source; Python manages ctypes/copies only.

Verification on Windows: `cargo test --workspace --all-targets` passes 31 tests, Python `unittest` passes 26/26 with no skips, `pip install .` builds a working native wheel, `tools/smoke_test.py` passes against source and installed wheel, and the shipped 3-frame fixture reconstructs its 120x330 truth page byte-exactly with known positions. The 15-frame regression suite also runs on Windows: truth 512x3306, output 512x3307, missing pixels 0; MAE 0.1267 / exact 99.819% with masks and MAE 0.1822 / exact 99.728% without masks. A six-scenario headless-browser regression auto-detected fixed headers/sidebars and produced clean content (MAE 0.01-0.53 after page padding). Version 0.9.1 adds automatic horizontal capture-drift registration, fixing doubled text in real-frame overlaps. Full research-prototype numerical parity, 30/UI/Japanese suites and cross-platform CI are still NOT verified. JPEG/video/HEIC/OCR and semantic segmentation are not supported. This is not a production-certified full UI restoration binary. Refer to `PORT_STATUS.md` for detailed differences and acceptance tests.
